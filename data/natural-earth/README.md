# Natural Earth boundary data

`ne_110m_admin_0_countries.geojson` is the Natural Earth 1:110m Admin 0
Countries layer, used only to draw the two maps in the generated atlas.

- Source: <https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson>
- Upstream project: <https://www.naturalearthdata.com/>
- Rights: public domain (Natural Earth data is free of copyright restrictions).
- Retrieved: 2026-11-23.

The file is a build input, not part of the published site. The maps are
generated into `site/index.html`; the page credits Natural Earth and states that
the boundaries do not imply recognition of borders or sovereignty.
